# Data included in MARSWalk

Start with ../DATA-AND-CALCULATIONS.md for the equations, assumptions and code locations.

- jezero-sites.csv: the four named rover locations used by the planner, exported from its actual JSON.
- recorded-weather.csv: every bundled daily weather row. `--` means missing, not zero. Temperatures are Celsius and pressure is Pa.
- data-catalog.json: source URLs, runtime paths, snapshot metadata, limitations and SHA-256 checksums.

The full route coordinates and elevation values already live in src/lib/jezeroNamedData.json and src/lib/jezeroWestElevation.json. They remain bundled and unchanged. Images are in public/assets/nasa/. CSV exports are for reading, not a second runtime data source. Edit the original data only with appropriate source verification, then regenerate exports.

This folder is public reference data. Personal notes, messages and mission state are stored separately in data/ and are not included in the ZIP. The globe downloads NASA Mars Trek tiles at runtime; the complete planetary mosaic is not bundled.

- worked-route-example.json: output generated by the actual namedRoute/preflight functions for the default named route, with inputs and unrounded results.

`planner-validation.json` is generated by `npm test`: independent optimiser comparisons and illustrative scenario results, not human performance measurements.

`revision-validation.json` contains the constrained fixed/adaptive comparison, worked example, advice timing and rendered-terrain geometry checks from `scripts/test_mission_revision.ts`.
